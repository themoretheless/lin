Рабочие копии при необходимости восстанавливаются из указанных Git-коммитов; COW untracked-артефакты — из age-снимка worktree-03 в `2026-11-02-session-preservation` с пользовательским закрытым ключом. UPDATE raw archive лежит рядом, все 2695 членов проверены по SHA256; scanner не обнаружил шаблонов GitHub credentials. Архив содержит исходные журналы как часть полной доказательной базы, отдельные новые log-файлы в Git не добавляются.

Аудит COW повторно прочитал и проверил все 15244 и 15349 членов двух архивов. UPDATE матрица пересчитана независимо от исходного analyze.py; синтетический test-protocol.py дополнительно подтвердил обнаружение пропусков, неверного binary, отрицательных/unavailable samples, дублей и проигрывающих target/control. Для batch-shape пересчитаны оба исходных набора; нового запуска тестов/бенчей этот аудит не представляет.

Итог зачистки: удалены COW, BTreeMap reference и UPDATE clone-elision worktree. Остались основной каталог и batch-shape.
