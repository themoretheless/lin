# Normal checkpoint stage diagnostic protocol

This is a diagnostic observer,not an optimization candidate. Baseline is the transaction-corrected,abort-guarded core at3c19bc075. The baseline probe is byte-identical to the previous Normal checkpoint diagnostic. Its original executable is reused only after every core source,Cargo input,probe and executable hash matches. Original/control use that exact binary; disabled/traced use a separately compiled binary with timers inserted only in Store::write_snapshot. No existing checkpoint statement is removed; all durability calls,publication order,32-commit interval and SQLite1000-page policy remain unchanged. Temporary source and example are restored after compilation.

Three rounds rotate five roles: original/control/disabled/traced Lin and original-probe SQLite. Each process performs1000 growing transactions of five dynamic inserts with complete supplied-field/multiplicity verification after normal close/reopen. Fifteen processes and15000 transaction observations. Per-transaction counter reads remain outside operation timing. Only traced role enables LIN_BENCH_CHECKPOINT_STAGES; all other processes clear it.

Seven sequential spans: fence acquisition; pre-snapshot WAL durable_sync; preparation/cold writes; snapshot encode/file sync/rename/directory sync; atomic HEAD publication; FTS persistence; compact truncate/seek/sync_all and counter reset. The whole checkpoint timer contains these phases and ends before JSON emission. Trace JSON is emitted on stderr before returning from checkpoint and therefore is included in the outer transaction timer. Disabled/original,traced/disabled,and same-binary control/original ratios are reported as observer diagnostics,not calibrated corrections. Interpreting the table as isolated syscall latency is invalid.

Each traced process has31 automatic checkpoints at generations32,64,...,992 plus two unmeasured close/reopen checkpoints at1001. Keep all99 frames,report only93 automatic frames; no outlier rejection. Aggregate phase share per frame then median within process; report process-level stage medians. Per-phase medians need not sum exactly to100%. Do not infer uninstrumented CPU shares or Linux performance from this macOS run.

verify.py independently reconstructs all counters,transaction medians,phase medians/fractions,observer ratios,binary identities and historical Git-object source hashes. It confirms no original checkpoint statement was removed from the instrumented source. check-audit.py verifies sensitivity to a negative stage duration,a missing automatic frame and an altered observer ratio using disposable copies. No source gate or all-peer objective is marked achieved.
