# First repeated current-runtime FULL WAL peer discovery

Local macOS ARM64, runtime equivalent to f37/b9f10bc77, benchmark source from 75265476b. Exact ordinary optimized Mach-O benchmark is preserved in raw.tar.gz with its source closure, all six original process outputs and diagnostic logs. Frozen input precedes measurement. No unchanged numeric retry was run. Each process executed eight fresh measured operations for each of four cases: 192 observations total. Every case validates a fresh operation before calibration and after measurement; explicit pragma, commit state and exact writer/reader or close/reopen checks passed. Independent audit reconstructs every original median and ratio and verifies source, binary and raw hashes.

1k: Lin lost all six processes. Median of process medians: Lin 1.802886 ms, SQLite 1.376198 ms; SQLite/Lin = 0.763331. Lin needs about 23.7% lower wall time to match this observed SQLite median, before any safety margin. 10k: Lin won all six processes, aggregate SQLite/Lin = 1.337436 (about 9.14 ms Lin vs 12.22 ms SQLite). This is one platform/contract; no engine-wide or cross-host win is claimed. Complete original values and all six ratios are in independent-audit.json.

Both cases retain default Lin embeddings, FTS, identity maps and wing/ts index. SQLite uses FULL WAL, pre-generated data and a prepared statement cache, one transaction with commit. Setup and fixture/output destruction are excluded. The old FULL+DELETE cases are unchanged. Normal Lin close may checkpoint, so readback is not a crash-recovery oracle. Different engine internals and checkpoint triggers are not declared equivalent.
