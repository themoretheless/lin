Baseline ce37cbc29 (f37 runtime), local macOS ARM64. Diagnostic-only ordinary optimized benchmark with temporary exec/persist timers; both source files restored byte-for-byte immediately after execution. Patches, exact diagnostic binary, raw case and all diagnostic output are archived with hashes. Selected case compare/durable_insert_wal_1k/lin completed eight measured observations and exact checked operation/reopen validation.

There are eleven observations per phase, including the eight measured operations and three untimed calibration/validation operations. These are not independent process replications. Median phase microseconds: row build 203, validation 62, embeddings 403 (text 59, vector batch 243, attachment 35); maintenance critical scope 568, including encoder startup/join and overlap; index 119, FTS 152, maps 44; encoder-thread transpose 121 and encode 376; checksum 32, write/preallocation/copy 41, durable sync 547. Actual committed data payload is 336968 bytes. Instrumented median wall is 2024.896 us; timer output has overhead and cannot be substituted for the ordinary peer baseline.

Transpose/encode overlap maintenance and must not be added as independent serial wall stages. The largest measured serial costs are embedding work and sync. Sync semantics are retained. Historical compression proposals already tested on this same payload are rejected: dictionary writer (2026-10-24-dictionary-wal-writer), narrow coordinates (2026-10-04-wal-narrow-coordinates), and sparse delta encode/write/sync feasibility (2026-10-24-sparse-delta-index-io). Their smaller frames did not qualify a durable latency improvement; this profile is not authorization to retry them unchanged.

A different CPU hypothesis is exact modulo specialization in HashingEmbedder: generic feature hashing currently divides by the runtime vector length for every unigram/trigram. Default dimension 768 permits constant-divisor code generation while retaining exactly the same hash slot and every vector bit. It requires independent reference-bit tests and new prospective native/durable/control qualification. No speedup or peer win is asserted here; all eight named peers remain in scope.
